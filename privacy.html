隐私政策

最后更新日期：2025 年 5 月 3 日

1. 概述

Handly（以下简称"我们"）重视您的隐私。本隐私政策说明我们如何收集、使用和保护您的个人信息。

2. 我们收集的信息

2.1 支付信息

所有支付通过 Paddle 处理。您在购买时提供的支付信息（信用卡号、支付宝/微信账户等）由 Paddle 直接收集和处理，我们不会接触或存储您的完整支付信息。

2.2 订单信息

Paddle 向我们提供以下订单信息以完成许可验证：

  • 电子邮件地址（用于发送许可证和收据）
  • 交易 ID 和购买日期
  • 购买的产品和金额

2.3 扩展使用数据

Handly 浏览器扩展在您的设备上本地运行。我们不收集任何浏览历史、网页内容或使用行为数据。所有工具的处理都在您的浏览器本地完成，不会上传到任何服务器。

2.4 网站访问数据

我们的网站 handly.cc 托管在 GitHub Pages 上，不设置任何追踪 Cookie，不使用任何分析工具。

3. 我们如何使用信息

我们仅将订单信息用于：

  • 验证您的软件许可
  • 发送购买确认和产品更新通知
  • 处理退款请求

4. 信息共享

我们不会出售、出租或与第三方共享您的信息，除非：

  • 法律要求
  • 保护我们的合法权益

5. 数据安全

支付安全由 Paddle（PCI DSS 一级认证）保障。我们采用合理的措施保护存储的订单信息。

6. 您的权利

您可以随时要求我们：

  • 查询我们持有的您的个人信息
  • 更正或删除您的个人信息
  • 停止接收营销邮件

请发送邮件至 support@handly.cc 提出请求。

7. Cookie

我们的网站 handly.cc 不使用 Cookie。Paddle 结账流程可能使用必要的会话 Cookie，详情见 Paddle 隐私政策。

8. 第三方服务

我们使用以下第三方服务：

  • Paddle — 支付处理。隐私政策：paddle.com/legal/privacy
  • GitHub Pages — 网站托管。隐私政策：GitHub 隐私声明

9. 隐私政策更新

本隐私政策可能不时更新。重大变更将通过网站通知。

10. 联系方式

如有隐私相关问题，请联系：support@handly.cc
